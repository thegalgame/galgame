网站说明：

为了尽可能的保证资源的安全性，本网页提供的资源统一采用压缩包的形式。下载后请先解压（手机专区提供apk除外)，可能会有多重压缩的形式，请解压缩到文件形式即可，遇到一些.jpg的删掉.jpg即可

若手机的apk是.apk.1，删除掉后缀.1即可使用

由于图像显示优化，拒绝了巨量base64编码的字符量，导致某些国区steam锁区的游戏无法获取图片链接（如“mirror")，则无对应图片

若有链接失效，或你有想要我找的补丁内容，请到页尾的联系方式中联系我

当游戏名称旁边带有✳️时，代表该游戏：由于常被ban，已将链接下架，有需要请联系我获取补丁。目前已将所有带✳️的链接更改为我的邮箱链接

本网站只有一人维护，更新将是不定期的更新方式。

简单版投稿框架

零代码基础也能 1 分钟搞定！只要改 3 个地方即可提交一个游戏。如果你想直接投稿链接，也欢迎直接向我投稿

步骤提示：

  1. 游戏下载链接：必须是 https:// 开头；百度盘请保留「?pwd=***」这段密码，否则别人打不开。
  2. 游戏名字：写中文即可，会显示在页面上。
  3. 游戏封面图：打开 Steam 网页 → 在游戏标题右侧封面图「右键-复制图像地址」→ 粘贴过来。（或者其他途径)

把下面代码整块复制，替换3处中文提示，然后发送给管理员即可。

<div class="content-item">
    <a href="https://xxx?pwd=xxx" target="_blank">
        <h3>在此输入你的游戏名字</h3>
        <img src="在此放入你的游戏图片链接">
    </a>
</div>

可选做法：如果想留名，可在 </a> 之前加
    <h4>投稿人：你的名字/联系方式</h4>
不需要就直接删除整行。

请注意不要把""删除，完整的比如：href="https://xxxxx?pwd=wx33"

专业版投稿框架

一次性新建「123 分区」并投放 456、789 两款游戏，支持搜索与别名。跟着 4 步走，完全照抄也能成功！

Step-1 新建分区（HTML）
把下面整块代码粘到页面最底部，已标红的ID、链接、图片名请换成自己的。

<section class="section" id="section-123">
    <div class="container">
        <div class="content-section">
            <h2>123 分区</h2>
            <div class="content-container">
                <div class="content-item" id="g_456">
                    <a href="https://xxx?pwd=xxx" target="_blank">
                        <h3>456</h3>
                        <img src="https://xxx/456.jpg">
                    </a>
                </div>
                <div class="content-item" id="g_789">
                    <a href="https://xxx?pwd=xxx" target="_blank">
                        <h3>789</h3>
                        <img src="https://xxx/789.jpg">
                    </a>
                </div>
            </div>
        </div>
    </div>
</section>

Step-2 告诉系统有新分区（manualMap）
在文件里找到 const manualMap = {，把下面一行粘到末尾，注意最后加英文逗号。

    '123 分区': 'section-123',

Step-3 让搜索能索引（searchData）
找到 const searchData = [，把下面 3 行粘进去，也要带英文逗号。

    { id: 'c_section123', name: '123 分区', type: 'category', target: 'section-123' },
    { id: 'g_456', name: '456', type: 'game', target: 'section-123' },
    { id: 'g_789', name: '789', type: 'game', target: 'section-123' },

Step-4（可选）模糊搜索别名
想让玩家搜“四五六”也能找到 456？在 const aliasMap = { 里追加：

    456: ['四五六', '四五六游戏'],
    789: ['七八九'],

常见坑提醒：

  • 所有链接必须 https:// 开头；百度盘一定保留 ?pwd=*** 这段密码。
  • 每行末尾英文逗号别漏，否则整个页面会报错。
  • ID 不要带空格，用下划线或数字都行。
